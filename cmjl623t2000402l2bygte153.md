Hey everyone! Today I want to share my experience of deploying a **Node.js application** on **AWS ECS Fargate** using **ECR**, **CloudWatch**, and proper **IAM roles**. I’ll explain step by step in simple English so you can also understand it easily.

This guide is perfect if you want to revise or prepare for interviews related to **AWS, DevOps, or cloud deployment**.

---

## Step 1: Launch an EC2 Instance

First, I launched an **EC2 instance** on AWS. I chose **Ubuntu** because it is easy to work with and widely used.  
This instance acts as my server where I will **build the Docker image** and push it to **ECR**.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649770742/ec26d0bb-ce87-4415-845b-b4e43da20ef4.png align="center")

---

## Step 2: Clone the Project from GitHub

Next, I cloned my Node.js project from **GitHub**:

```plaintext
git clone <your-repo-link>
cd <project-folder>
```

This way, all my project files are on the EC2 instance.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649858022/77a16f43-2919-4ed4-8ee3-cf9e60e907ab.png align="center")

---

## Step 3: Create a Repository on ECR

I went to **AWS ECR (Elastic Container Registry)** and created a new repository.  
This repository is where I will **store the Docker image** of my Node.js application.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649878317/2154c80c-448b-4d07-ae0c-2b645c0f11c5.png align="center")

---

## Step 4: Install Docker and Add User to Docker Group

Docker is required to create containers. I installed it on my EC2 instance:

```plaintext
sudo apt update
sudo apt install docker.io -y
sudo usermod -aG docker $USER
```

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649897315/4ba4d840-34b6-4fa3-b902-1bf527b4c219.png align="center")

Adding the user to the **docker group** allows me to run Docker commands without using `sudo` every time.

---

## Step 5: Install AWS CLI

I installed **AWS CLI** so that I can interact with AWS services directly from my EC2 terminal:

```plaintext
sudo apt install awscli -y
aws configure
```

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649948748/dbf13b8c-58a9-45e5-808e-ef722bd83e39.png align="center")

Here, I entered my **IAM user access key, secret key, region**, and output format.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766649933029/ef96eab2-d59d-446c-948c-1294afd368cc.png align="center")

---

## Step 6: Create an IAM User and Access Key

I created a new **IAM user** with permissions for **ECR, ECS, and CloudWatch**.  
Then I generated the **access key** to configure the AWS CLI.

IAM roles and access keys are important for security and automation.

---

## Step 7: Build the Docker Image

After setting up everything, I built the Docker image of my Node.js app:

```plaintext
docker build -t node-app .
```

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766650019363/5b61f9a2-4d71-4110-bdf3-f9ef17d7383c.png align="center")

Then I pushed it to the **ECR repository**:

```plaintext
aws ecr get-login-password --region <region> | docker login --username AWS --password-stdin <account-id>.dkr.ecr.<region>.amazonaws.com
docker tag node-app:latest <account-id>.dkr.ecr.<region>.amazonaws.com/node-app:latest
docker push <account-id>.dkr.ecr.<region>.amazonaws.com/node-app:latest
```

---

## Step 8: Create an ECS Cluster

Next, I created a **cluster in ECS**.  
This cluster will run my Node.js application in a **serverless container** using **Fargate**.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766650042455/b1d3c0f4-5efd-4116-9a9f-b508a53ac1dc.png align="center")

---

## Step 9: Create a Task Definition

Instead of running `docker run` manually, I created a **task definition**.

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766650057479/000547c5-39ce-4a2c-a7b1-1cf97c52fa3a.png align="center")

This task definition specifies:

* Docker image location
    
* CPU and memory requirements
    
* Port mapping (I used port 8080)
    

---

## Step 10: Assign IAM Role for Task Execution

I created an **IAM role for ECS task execution**.

  
This role allows the ECS task to **pull the image from ECR** and **send logs to CloudWatch**.

IAM roles make the deployment **secure and automated**.

---

## Step 11: Launch the Task

With everything ready, I launched the ECS task.  
Fargate automatically created the infrastructure, so I didn’t have to manage servers manually.

---

## Step 12: Access the Application

I copied the **public IP of the ECS task** and accessed my Node.js app in the browser:

```plaintext
http://<public-ip>:8080
```

![](https://cdn.hashnode.com/res/hashnode/image/upload/v1766650125200/5d12b9ae-577c-483b-926f-6417e5978012.png align="center")

It was running perfectly!

---

## Step 13: Monitor Logs with CloudWatch

Finally, I went to **CloudWatch** to check logs and events.  
This is useful to **debug and monitor** your app.
